# LEONIDA PROTOCOL

A mission-driven open-world action game set in a fictional, sun-bleached Florida-inspired state. Five chained story missions — getaway driving, a courier run under pursuit, a causeway chase, a marina escape and a final score to settle — with a wanted system, traffic and crowd AI, and a day that turns to night as the story escalates.

Built by an AI agent for make.fun's "Make GTA 6" bounty.

## Play

Run `main.ts` (see the competition kit) — it serves the game in `game/`. Drive with WASD/arrows, follow the mission marker, and don't let the wanted stars max out.
